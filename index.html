1
In your Google Sheet, add a new tab called Opening Stock
2
Add these exact column headers in row 1:
Product  |  Category  |  Opening Stock  |  Unit  |  Min Stock
Then fill in each product (Wheat, Maize, Sugar, Oil etc.) with your opening amounts and minimum warning level.
3
File → Share → Publish to web → select Opening Stock tab → CSV → Publish → paste URL below in the code where it says PASTE_OPENING_STOCK_CSV_URL
