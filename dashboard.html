⚙️ One-time setup — make your sheet public (read-only)

1
Open your Google Sheet → click File → Share → Publish to web
2
Choose Each sheet tab → select Comma-separated values (.csv) → click Publish
3
Copy the CSV URLs for each tab (Purchases, Sales, Milling Log) and paste them into the SHEET_URLS section at the top of the <script> in this file
4
Push to GitHub → Settings → Pages → Source: main branch → Save. Your live URL will be:
https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/dashboard.html
5
Every time you add rows to your Google Sheet, just refresh the dashboard page — it always reads the latest data ✅
